# Лабораторна робота №7: Хмарне розгортання DevOps-сервісу

**Тема:** Хмарний deployment Docker-контейнера з Flask API на платформу Render.  
**Виконав:** Пташников Василь, група АІ-235.  
**Модель:** Метод Ньютона (5 семестр).

---

## Опис процесу розгортання та безпеки

Сервіс успішно розгорнуто у хмарному середовищі **Render** з використанням Docker-контейнеризації.

### Реалізовані вимоги безпеки:
1. **Вимкнено Debug Mode:** У коді `main.py` запуск виконується суворо з параметром `debug=False`.
2. **Environment Variables & Secrets:** Усі конфіденційні та конфігураційні дані (`STUDENT_NAME`, `GROUP`, `MODE`) винесені в змінні середовища панелі керування хмарою.
3. **Відсутність хардкоду:** У коді немає збережених паролів чи статичних секретів.

### Рівень Advanced (Додаткові бали):
* **Auto deploy через CI/CD (+2 бали):** Налаштовано автоматичний деплой при кожному коміті в GitHub.
* **Environment secrets (+1 бал):** Змінні конфігуруються через захищений розділ Environment платформи Render.
